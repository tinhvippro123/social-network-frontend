# TÓM TẮT ĐỒ ÁN

Các nền tảng chia sẻ nội dung hiện nay phần lớn sử dụng tìm kiếm theo từ khóa cứng, không hiểu được ngữ cảnh của truy vấn; thiếu khả năng tìm kiếm bằng hình ảnh hoặc tài liệu; và chưa có cơ chế xếp hạng bài viết xu hướng một cách khoa học. Xuất phát từ những hạn chế đó, đồ án đã thiết kế và xây dựng nền tảng web quản lý bài viết và tương tác nội dung VietBlog theo phương pháp phát triển phần mềm hướng đối tượng, áp dụng kiến trúc Clean Architecture và các nguyên lý thiết kế SOLID xuyên suốt toàn bộ hệ thống.

Hệ thống được xây dựng theo mô hình Client-Server với Vue.js 3 (TypeScript, Composition API) cho Frontend và Spring Boot 3 (Java) cho Backend, kết hợp PostgreSQL (pgvector) và Redis, phân tách thành 4 tầng theo Clean Architecture: Domain (Entity, Repository Interface), Use Case (nghiệp vụ ứng dụng), Adapter (Controller, DTO, Mapper) và Infrastructure (JPA, Security, Redis, WebSocket). Các Design Patterns được áp dụng bao gồm Repository Pattern, Composition Pattern qua Vue Composables, Observer Pattern qua WebSocket kết hợp Redis Pub/Sub, Strategy Pattern cho đa chế độ tìm kiếm và Singleton Pattern cho State Management. Hệ thống tích hợp 3 nhóm tính năng AI: tìm kiếm ngữ nghĩa Semantic Search sử dụng TF-IDF và Cosine Similarity cho phép tìm bài viết theo ý nghĩa thay vì chỉ so khớp từ khóa, tìm kiếm theo hình ảnh và tài liệu Image & Document Search cho phép upload hình ảnh hoặc tài liệu để tìm bài viết liên quan, và giải thuật xếp hạng xu hướng Trending Ranking tự động tính điểm xu hướng bài viết dựa trên mức độ tương tác và hệ số suy giảm theo thời gian.

Bên cạnh các tính năng AI, hệ thống đảm bảo đầy đủ các chức năng nghiệp vụ: đăng ký/đăng nhập bảo mật JWT với Role-based Access Control, quản lý bài viết CRUD với TipTap Rich Text Editor, hệ thống bình luận lồng nhau, bình chọn upvote/downvote, lưu bài viết bookmark, quản lý nhóm cộng đồng, chat thời gian thực qua WebSocket kết hợp Redis Pub/Sub, hệ thống thông báo, và trang quản trị Admin với dashboard thống kê, kiểm duyệt nội dung và quản lý người dùng. Frontend áp dụng mô hình View → Composable → API Layer để tách biệt hoàn toàn giao diện khỏi logic nghiệp vụ, sử dụng Pinia cho State Management và xây dựng Design System với các Design Tokens đảm bảo tính nhất quán giao diện, hỗ trợ Dark Mode và Responsive Design.

Kết quả thực hiện cho thấy hệ thống hoạt động ổn định, giao diện responsive, các tính năng AI hoạt động chính xác trên bộ dữ liệu thực tế. Đồ án đã đạt được các mục tiêu đề ra về cả chức năng nghiệp vụ lẫn thiết kế hướng đối tượng. Hạn chế hiện tại là chưa có unit test tự động và chưa tối ưu hiệu năng tìm kiếm trên tập dữ liệu lớn. Hướng phát triển tiếp theo bao gồm bổ sung kiểm thử tự động, tối ưu indexing cho pgvector, và mở rộng tính năng gợi ý bài viết liên quan.
